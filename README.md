# AMF Systems — sitio web institucional

Sitio estático listo para GitHub Pages. Incluye presentación empresarial, servicios, staff y contacto.

## Publicar en GitHub Pages
1. Inicia sesión en GitHub y crea un repositorio **público** llamado `amf-systems-web` (o cualquier nombre disponible).
2. Sube **el contenido de esta carpeta** (no el ZIP cerrado) mediante **Add file → Upload files**, conservando `index.html`, `styles.css`, `script.js` y `assets/` en la raíz. Haz clic en **Commit changes**.
3. En el repositorio abre **Settings → Pages → Build and deployment → Deploy from a branch**. Selecciona **main** y **/(root)**. Guarda.
4. Cuando GitHub publique el sitio, tu dirección será `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`. Verifica la URL real en **Settings → Pages** antes de colocarla en WhatsApp Business.
